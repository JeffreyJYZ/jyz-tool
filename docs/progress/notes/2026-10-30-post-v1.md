# 2026-10-30 — after v1: machine surfaces

Everything added after the v1 milestone report. Same day, version line `0.1.0-alpha.3` → `alpha.4`.

## Landed

- **CLI JSON-RPC** — `jyz serve` reads newline-delimited JSON-RPC 2.0 on stdin and answers on stdout; methods are capability names; it resolves argv and never spawns. `listCapabilities()` in core is the manifest, and `serve` is hidden from help but still a core verb.
- **MCP** — 15 tools including `jyz_watch`/`jyz_cancel` with progress frames, plus `jyz://config` and `jyz://capabilities` resources served over `resources/list` and `resources/read`. Unknown URI maps to `-32602`.
- **Desktop bridge** — `jyz_call` and `jyz_version` Tauri commands spawn `jyz serve`, one frame each way, child killed after. The window's method list is derived from the capability manifest (`methodsFromManifest`, `groupByKind`), grouped by kind.
- **opencode seam** — `resolveServer` (flag → env → default `http://127.0.0.1:4096`), `listSessions`, `sendPrompt`, `OpencodeError`; exposed as hidden `jyz oc <action> [...text]`.
- **`--json`** — one document on stdout for `config show|get|path|check`, every dispatch verb, `create`, and the toolchain verbs; exit codes unchanged; prose moves to stderr.
- **Release tooling** — `verify-release` (pure `checkAssets`, real run), `release-notes` (git history → markdown), `alpha-release` (gates → bump → commit → tag, `--dry-run`, `--push`), `bench` (p50/p95 startup and dispatch).
- **Toolchain coverage** — eslint, clang-tidy, clang-format, rustfmt, prettier, clang, cargo, plus `paths` argument and check-mode variants.
- **CI** — `bun run test` added (it was missing), a `rust` job running `cargo fmt --check` and `cargo check --locked`, and `rustfmt.toml` with `hard_tabs` so Rust matches house style.

## Traps recorded

- `cac` v7 has no nested commands: `command("oc sessions")` never matches. Use one command with a positional action and `[...rest]` for variadic args.
- Tauri v2 rejects unknown ACL entries: `allow-jyz-call` in `capabilities/default.json` fails `cargo check` unless the app defines that permission. App commands need no entry.
- `bun test` can print "0 fail" and still exit 1 when a test leaves `process.exitCode` set. Restore it to `0`, never to a captured value.
- A tracked path containing a newline or quote breaks Windows checkout before any CI step runs; `scripts/test/tracked-paths.test.ts` now fails on that class of name.
- Free-tier dispatches die account-wide at once; the Vercel `beam-free` twin needs `reasoning_content` on prior turns, so only cross-model resumes fail there.

## Still open

- MCP streaming is handler-level only; no host has driven it end to end.
- Desktop parity is a manifest test, not a UI walkthrough.
- `--git github` remains stub-tested only.
- opencode integration talks to a server it never starts; spawn mode is unimplemented.

## Measured 2026-10-30 (macOS arm64, `bench --runs 3`)

- `jyz --version` — p50 13.8 ms
- `jyz config path` — p50 13.9 ms
- `jyz run` on a no-op script — p50 20.3 ms

Each dispatch word is a child process, so the floor is process spawn plus one config read.

## Close-out 2026-10-30, alpha.5

- Desktop takes its methods from `jyz capabilities --json`; `parity.test.ts` asserts every core capability is selectable.
- MCP smoke is seven steps, including `jyz_watch` progress and `jyz_cancel`.
- `scripts/alpha-release.ts` is the release path: gates, bump, commit, tag, optional push.
- Guards added: uncheckoutable tracked paths fail a test (must scan from the repo toplevel — `git ls-files` in a subdirectory lists only that subdirectory, which is how a junk name slipped through), and test files must never leave `process.exitCode` non-zero.

## v2 close-out, alpha.6

- **Desktop installer carries the CLI.** `bundle.externalBin: ["binaries/jyz"]`; `packages/desktop/scripts/stage-sidecar.ts` compiles the CLI for the rust host triple into `src-tauri/binaries/jyz-<triple>` (gitignored) and `bun run build` chains it. The shell resolves a sibling `jyz` before `PATH`, so an installed app never depends on the user's shell.
- **Three desktop screens**: call runner, config viewer (`config show` rendered as key/value/source), opencode panel (`jyz oc sessions --json`, prompt send, 5 s watch that marks changed session ids).
- **`jyz oc --json`** prints one document; prose output is byte-identical to before.
- **MCP distribution**: `@jyz/mcp` declares a `jyz-mcp` bin, `files`, engines and publishConfig (still `private`), and the release builds `mcp-<version>.tgz` plus one compiled binary per target.
- **Release gate**: the publish job runs the parity test and asserts a non-empty capability manifest before uploading.
- **Click-through**: the page was driven in a browser with `__TAURI_INTERNALS__` stubbed — tabs switch, Run returns a frame, Config renders two rows, opencode lists two sessions and reports `sent to ses_alpha`.

Traps found: a `const` reached by a function called before its initializer is a TDZ `ReferenceError`, so the first render now runs last; biome flags `useButtonType` as an error in HTML-inlined markup.
